Privacy

Your data stays
on your PC.

Agent Notch has no Agent Notch account and no analytics SDK. This page explains exactly when content leaves your computer and what is stored locally. It describes the current Windows build, not a future mobile or cloud service.

Local profile. Settings, encrypted provider keys, notes, reminders, history, reading/workout/water records and SQLite data are stored under %APPDATA%\agent-notch. Updates replace the application files, not this profile. Uninstalling keeps notes and history by default but removes saved provider keys, integration secrets and the local agent token.
Offline speech. When Local (Windows, offline) is selected, dictation audio is handed only to the Windows speech recognizer on this PC. It is not sent to an Agent Notch server or a cloud provider. Cloud providers remain a separate choice.
File actions. Image conversion runs locally and writes a new file you choose. The original is never overwritten. Video, audio and document packs are not bundled yet; when added they will use hash-verified local tools and the same explicit action model.
Provider calls. A cloud request happens only when you start a chat, dictation, screen question or spoken reply. The selected provider receives the content required for that action: text, audio or a captured screen image. The app does not send background telemetry or a transcript of unrelated activity.
Keys. Provider keys are encrypted with Windows secure storage and remain in the main process. The renderer cannot read saved credentials. Keys are never written to release notes, update metadata or the public website.
Screen and microphone. Capture starts from an explicit button or shortcut and shows an indicator. Target windows are revalidated before a grounded click. Microphone access follows the saved listening mode and the Windows privacy setting; muting releases recognition.
Terminal. The manual terminal is a separate reviewed session. Agent Notch does not log terminal content or send it to an AI provider. Child programs can write their own files.
Updates. The app contacts the public release channel for latest.yml and the installer. No account identifier is sent. The downloaded installer is verified against the published hash before it is offered.
Website. This site uses no analytics, cookies or third-party scripts. The browser may request release metadata from the GitHub API to show the current version and checksum; GitHub receives the request under its own policies.
