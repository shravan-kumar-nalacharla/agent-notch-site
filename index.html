What it does

Small island.
Real work.

Agent Notch is not another chat window. It is a compact surface for the things you do between apps: speak a sentence, ask about the screen, skip a track, start a focus block, log water, remember a note.

Speak into the app you are already in

Hold Ctrl + Shift + Windows, speak, release. The reviewed transcript types into the field where you started. Password fields and elevated windows are blocked by design.

System-wide dictation

Ask about the screen, only when you choose

A capture starts from an explicit click or shortcut. The target is rechecked before any grounded click. The screen is never monitored in the background.

Explicit capture

Media and lyrics that stay legible

Play, skip, seek and change system volume from the notch. Synchronized lyrics show the current line and the one before it, without a third clipped row.

Windows media session

Focus, water and reminders together

A focus timer, stopwatch, hydration goal, reading and workout plans, notes, tasks and reminders share one local store and one quiet surface.

Daily tools

A reviewed terminal, not a hidden shell

Open a manual PowerShell, PowerShell 7 or CMD session after a native review. The assistant planner has no terminal action, and no shell opens on restart.

Explicit intent

Drop a file. Keep the original.

File actions detects an image, shows its size and converts PNG/JPEG or resizes it to a new file. Conversion is local and the source is never overwritten.

Local file actions

Make the agent yours

Choose a blob shape, hue and expression. It replaces the two eyes, stays inside its stage and reacts when you click it.

Privacy

Local by default.
Cloud only when you ask.

Your notes, reminders, history and encrypted provider keys stay on your PC. Agent Notch sends content to a provider only when you start that action: a dictation, a chat message, a screen question, a spoken reply.

  • No Agent Notch account, no analytics SDK and no background screen monitoring.
  • Provider keys are encrypted with Windows secure storage and are never exposed to the UI.
  • Uninstall keeps notes and history by default but always removes saved API keys and integration secrets.

Install

Three minutes.
One installer.

Download the current installer

Use the button on this page. It always points at the latest release in the public channel.

Run Agent-Notch-Setup.exe

The per-user installer does not need a browser extension, a separate runtime or an account. It creates Start menu and desktop shortcuts.

Choose your providers, or skip for now

Open Settings → Providers to add the API keys for the services you already use. The app stays usable without a key for local tools; cloud answers need a provider.

Use the open shortcut

The default is Ctrl + Shift + Space. The notch stays as a faint line until you hover or call it.

Windows SmartScreen: this build is not code-signed, so Windows may say “Windows protected your PC”. Choose More info → Run anyway only after comparing the SHA-256 checksum on the release page. A signed build will replace it through the normal update path.

Updates

It updates quietly,
with your permission.

Agent Notch checks shortly after startup, every six hours and from Settings. A downloaded update waits until you choose Restart now. Installation is deferred while you are recording, capturing, using the terminal, editing unsaved settings or running a task.

Questions

Before you
install.

Straight answers about signing, accounts, data and the update path.

Is the installer really the latest version?

Yes. The download button points at the latest non-prerelease GitHub release. The website also reads that release’s latest.yml and checksum file, so the version and size on this page come from the channel itself.

Why is the app unsigned?

Code signing requires a paid certificate and a verified publisher identity. This release is unsigned, so Windows SmartScreen may warn. The checksum is published so you can verify the exact bytes. A signed build will use the same update channel.

Do I need an Agent Notch account?

No. Agent Notch has no account system. Cloud providers such as Groq, OpenAI, Gemini or DeepSeek are optional and use keys you enter and encrypt locally. Local widgets and system tools work without a key.

What happens to my data when I update or uninstall?

Settings, encrypted keys, notes, reminders, history and SQLite data live in your Windows profile, outside the installed folder. Updates keep them. The uninstaller keeps them by default; deleting them is a separate option.

Does it work on Windows 10?

Agent Notch targets 64-bit Windows 10 and Windows 11. Some physical microphone, insertion and multi-monitor combinations still need user-level validation; the release notes are the source of truth for what has been tested.
