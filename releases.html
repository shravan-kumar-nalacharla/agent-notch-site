Agent Notch ships from a public release-only channel. The app checks it shortly after startup, every six hours and on demand. This page is the human-readable history: current notes, previous builds and the update path.

Release notes in the app live under Settings → About → What’s new. The same history is published here so you can read it before installing, or check what a friend is running.

09 November 2026 Current

0.20.1 — Square crop, Groq still default

Small follow-up to 0.20.0.

  • File actions can center-crop to a square before converting or resizing.
  • Groq remains the default assistant and transcription provider.
  • Local (Windows, offline) remains an explicit alternative with no key or cloud consent.
09 November 2026 Current

0.20.0 — Local speech, no API key

Dictation and recorded voice can now use the speech recognizer already installed in Windows.

  • Choose Local (Windows, offline) for Dictation & recorded voice.
  • No provider key and no cloud-audio consent; audio stays on the PC.
  • Cloud providers remain the default and are unchanged.
  • Quality and language support depend on the installed Windows speech pack; this is not a Whisper model.
Still optional: Handy-style Whisper/Parakeet packs are not bundled. Their models are far larger than the installer headroom.
09 November 2026 Current

0.19.0 — Keys leave, lyrics hold still, agent face

Fixes the post-0.18.0 regressions and starts the file and agent-face work.

  • Uninstall removes provider keys, integration secrets and the local agent token even when notes and history are kept.
  • Lyrics render only the current and previous full lines; the current line no longer restarts for every word.
  • Appearance gains a deterministic blob companion with five shapes, hue, five expressions, preview and click reaction.
  • File actions: drop or choose an image, inspect it, convert PNG/JPEG and resize to a new file. The original is never overwritten.
  • The PRD covers optional FFmpeg/LibreOffice packs, Handy-style offline speech and the Rune/Astryx evaluation.
Not in this build: offline Whisper/Parakeet models, video/audio/document conversion and the full crop/trim editor. Those need optional packs so the installer stays under 1 GB.
09 November 2026 Previous

0.18.0 — Clearer lyrics, a quieter chat, a notch that leaves

This release fixes the three visible problems in the island and adds the release-note experience.

  • Lyrics show only the current line and the line before it. The current line is larger and bold; the previous line is smaller and faded. A third clipped row is gone.
  • The chat no longer opens with “Ask a question” or an empty-state paragraph. The conversation and composer get the space.
  • The island closes after the pointer leaves, unless it is pinned or voice, capture, a task or a manual terminal session is active.
  • Settings → About includes What’s new, and this public update catalog is linked from the app and the website.
Install: this is the current direct download. Existing 0.17.1 installations need one manual 0.18.0 install because 0.17.1 has no updater. Builds 0.17.2 through 0.17.7 may not install automatically; install 0.18.0 manually if you are on one of them.
09 November 2026 Verified updater

0.17.9 — Automatic updates are live

  • Checks 15 seconds after startup, every six hours and from Settings.
  • Downloads in the background, then offers Restart now or Later.
  • Installs only after the app exits, through a WMI-created helper that survives the app process job.
  • Stops voice, agents, capture and the browser, closes the native helper, checkpoints SQLite and preserves the local profile.
  • Verified installed 0.17.8 → 0.17.9: discovery, download, silent install, relaunch and profile marker.

0.17.8 — Installer hand-off hardening

  • Created the install helper through Windows Management Instrumentation so it survives the app process ending.
  • Checkpointed and closed widgets, timers, capture, voice, agents, the managed browser, the native helper and SQLite before shutdown.

08 November 2026 Historical

0.17.1 — Player, settings and interruption fixes

  • Settings focuses on first load; music got a full-width seek bar, output waveform and system-volume slider.
  • Synchronized lyrics show the current line and the preceding line; future lines stay hidden.
  • Voice stop/hide/quit control and prefetched speech segments.
  • No updater. This is the build that needs a one-time manual install of 0.18.0.

The update path

The app reads latest.yml from the latest non-prerelease GitHub release. The installer is downloaded and verified, then a helper waits for the app to exit before running the NSIS package. A version tag is never overwritten; a bad release is fixed with a higher version.

0.17.1 → 0.18.0: manual install once. 0.18.0 → future: automatic. The public channel is agent-notch-releases.
