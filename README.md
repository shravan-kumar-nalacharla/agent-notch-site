# Agent Notch website

Product site, install guide, live notch preview and release catalog for **Agent Notch for Windows** by **Huygen Studios**.

- Production: https://shravan-kumar-nalacharla.github.io/agent-notch-site/
- Download channel: https://github.com/shravan-kumar-nalacharla/agent-notch-releases/releases
- Source of this site is also kept in the private Agent Notch source repository under `site/`.

The site is static HTML/CSS/JavaScript. No analytics, no cookies, no third-party scripts. Release version and checksum are read from the public release channel when the browser allows it, with static fallbacks.
